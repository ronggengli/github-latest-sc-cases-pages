Github_Latest_SC_Cases

Github_Latest_SC_Cases 是一個個人使用的自動化工具，每日從司法院公開資料開放平臺取得最新刑事裁判書，依關鍵字（例如通訊保障及監察法、數位證據、科技偵查等）篩選，產生摘要後，以電子郵件寄送給應用程式擁有者本人。

功能說明

  • 透過司法院「裁判書開放資料」API 取得公開之裁判書。
  • 依關鍵字篩選出相關案件，並以 Google Gemini API 產生重點摘要。
  • 透過 Gmail API 將摘要信寄出，收件者為應用程式擁有者本人。

Google 使用者資料的使用

本應用程式僅申請一項 Google OAuth 權限範圍：https://www.googleapis.com/auth/gmail.send（僅限寄送電子郵件）。

  • 不會讀取、搜尋、列出或刪除任何信件、聯絡人或其他 Google 帳號資料。
  • 該權限僅用於以擁有者本人的 Gmail 帳號寄出上述每日摘要信。
  • 本應用程式為個人使用，不對外提供服務，也不會處理其他使用者的資料。
