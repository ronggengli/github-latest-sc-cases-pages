隱私權政策

Github_Latest_SC_Cases　｜　最後更新：2026 年 10 月 30 日

本政策說明 Github_Latest_SC_Cases（以下稱「本應用程式」）如何處理資料。本應用程式為個人使用之自動化工具，使用者僅有應用程式擁有者本人。

1. 我們存取的 Google 使用者資料

本應用程式僅申請下列 OAuth 權限範圍：

  • https://www.googleapis.com/auth/gmail.send：僅用於以擁有者本人的 Gmail 帳號寄出電子郵件。

本應用程式不會讀取、搜尋、列出、修改或刪除任何信件、聯絡人、日曆、雲端硬碟檔案或其他 Google 帳號資料。

2. 資料的使用方式

取得之授權僅用於寄送由本應用程式自動產生的「最新裁判書摘要」郵件給擁有者本人。裁判書內容來自司法院公開資料開放平臺之公開資訊，並非 Google 使用者資料。

3. 資料的儲存與保護

  • OAuth refresh token 與用戶端憑證僅存放於擁有者自行控管的環境（例如 GitHub Actions Secrets 或本機環境變數），不會寫入程式碼、公開儲存庫或日誌。
  • 本應用程式不建立資料庫，不儲存任何 Google 使用者資料；僅在本機記錄已處理的裁判書案號，以避免重複通知。
  • 憑證若遭外洩疑慮，擁有者可隨時於 Google 帳號的「第三方存取權」頁面撤銷授權。

4. 資料分享與揭露

本應用程式不會出售、出租、交易或以其他方式向任何第三方分享 Google 使用者資料，亦不將其用於廣告、資料仲介或訓練通用 AI／機器學習模型。

為產生摘要，本應用程式會將公開的裁判書文字傳送至 Google Gemini API；傳送內容不包含任何 Google 帳號資料。

5. Google API 服務使用者資料政策

本應用程式對從 Google API 取得之資訊的使用與轉移，遵守 Google API 服務使用者資料政策，包含其中「有限使用」之規定。

6. 撤銷授權與資料刪除

擁有者可隨時前往 Google 帳號第三方存取權頁面撤銷本應用程式的存取權限。撤銷後，本應用程式即無法再寄送郵件。由於本應用程式不儲存 Google 使用者資料，無其他待刪除之資料。

7. 政策變更

本政策如有修訂，將更新於本頁並標示更新日期。

8. 聯絡方式
